# 花生返图 App

手机端实拍返图工具，连接电脑上的花生工作台。

## 开发运行

```powershell
cd mobile
npm install
npx expo start --lan --clear
```

电脑和手机连接同一个 Wi-Fi。iPhone 用自带相机的扫码功能扫描终端二维码，选择在 Expo Go 中打开。

## 首次配对

1. 电脑打开花生工作台
2. 系统设置 → 手机返图 → 生成手机配对码
3. 手机 App 输入电脑显示的地址和 6 位配对码

## 当前功能

- 设备配对
- 按手机号、订单号、地址搜索订单
- 扫描订单标签（本地后端 OCR）
- 自动识别麦芽田号、手机号
- 查看订单商品
- 相机 3:4 预览、变焦、闪光灯、切换镜头
- 连续拍摄多张、删除单张、清空
- 上传实拍图并自动标记已拣货

## 注意

工作台需要允许局域网访问 8787 端口，手机和电脑必须在同一 Wi-Fi。
